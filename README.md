# Misión 1 - Programación web

Primera misión: conseguir hacer un juego sencillo usando HTML, CSS y JavaScript sin usar librerías. El juego consiste en el Simón Dice, donde tienes que seguir el patrón de colores que va reproduciendo la máquina.

## Uso de IA

Dos prompts reales que me ayudaron a entender la lógica de algunas funciones, como `reproducirSecuencia()`, una función que muestra al jugador los colores seleccionados por la máquina con un retraso entre cada color:

- "pero no quiero que me lo des del tirón, quiero construirlo poco a poco sin copiarlo para aprender, mi primer paso sería conseguir que se vea lo que hace la máquina"
- "o sea, en el primer parámetro de setInterval va una función que tiene que llamar a la función por índices, avanzar el índice y comprobar si ha llegado al final"

## Autopsia

Tenía dos opciones para hacer el Simón Dice: la primera era hacer un tablero 3x3, y la segunda, simplemente recrear el círculo del Simón Dice. Finalmente me decanté por la segunda.
