# Mision-1-Programacion-web
Primera mision, conseguir hacer un juego sencillo usando html, css y javascript sin usar libreria. El juego consiste en el Simón dice donde tienes que seguir el patrón de colores que va reproduciendo la máquina.

Uso de IA
Dos prompts reales que me ayudaron a entender la logica de algunas funciones como reproducirSecuencia(), una funcion que muestra al jugador los colores seleccionados por la maquina con un retraso entre cada color.
